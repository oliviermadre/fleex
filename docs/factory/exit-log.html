Ce qui est sorti par une exit

Un double-clic sur une exit montre les tickets qui y sont passés sur la période des stats (7 jours par défaut, comme le compteur « 0 · 7 d » de l'exit), dans une liste du même genre que celle de Tab. Les données existent déjà : chaque sortie est une ligne des runs du Factory, avec l'heure de prise en charge et l'heure de sortie.
