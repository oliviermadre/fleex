Le HUD, version jeu de stratégie

Une seule scène, jouable : sélection additive avec Maj, groupes à place fixe, une icône par item sélectionné, un avatar, l'heure, une carte de commandes de 5 sur 3 dont les touches suivent le clavier, et un contour qui n'est plus une ligne droite. Rien n'est dans le code.

À essayer

  • Sélection : clique un ticket ou une machine ; Maj+clic en ajoute un (ou le retire s'il y est déjà) ; un glisser dessine un cadre, Maj+glisser ajoute au lieu de remplacer. Sur le plancher on sélectionne des tickets, en mode Build des machines.
  • Groupes : Maj+1…0 range la sélection, 1…0 la rappelle. Chaque groupe a sa place, ne se montre que s'il est rempli, et garde la même taille. Survole-le.
  • Plusieurs items : une icône chacun au centre. Survol : le détail. Clic : ne garder que lui. Maj+clic : le retirer.
  • Carte de commandes : 5 sur 3, les touches sont celles du clavier dans le même ordre. B entre en mode Build et en sort, toujours en bas à droite.
  • Mode Build : le ruban suit le contour du HUD. U cache le HUD, le ruban redevient un cadre droit.

Ce que je propose, au-delà de ta demande

  • Maj est additif partout, pas seulement en mode Build : sur le plancher aussi, pour les tickets.
  • Les touches sont liées à la position, pas à la lettre : la touche en haut à gauche lance la commande en haut à gauche, quel que soit le clavier. Seule l'étiquette change. Le navigateur sait donner la disposition (Chrome, Edge, l'app Electron) ; sinon elle se déduit de la première touche tapée, et un réglage permet de la forcer.
  • La dernière ligne ne bouge jamais : Undo, Redo, Next, et en bas à droite Build / Done / Previous. Fit garde la touche F, qui tombe au même endroit sur les deux claviers.
  • N, Tab, Suppr et Échap continuent de marcher en plus de la touche de grille.
  • Le portique Set passe dans le menu Move, à côté du péage : les deux se posent sur un convoyeur.

La carte de commandes, menu par menu

Les mêmes commandes aux mêmes places d'un menu à l'autre. Les étiquettes de touches suivent le réglage « Clavier » ci-dessus.

Les avatars

Un pour chaque chose qu'on peut sélectionner. Un ticket montre son objet en grand, qui penche doucement devant un halo de sa couleur ; une machine montre ce qu'elle fait.

Ce qui reste à trancher

  • Le contour : C1 marches droites ou C2 pans coupés (bascule au-dessus de la scène).
  • Un groupe d'un seul ticket montre son icône et son numéro ; d'une seule machine, son icône seule. Faut-il un mot sous l'icône d'une machine ?
  • Au-delà de 24 items sélectionnés, je propose des pages comme dans le jeu (24 par page) plutôt qu'un défilement.
  • L'avatar générique : l'usine sur le plancher, le casque de chantier en mode Build. D'autres idées bienvenues.
  • Les objets des tickets sont ici redessinés à la main ; dans l'app ce seront les vrais objets 3D déjà utilisés sur le plancher.
