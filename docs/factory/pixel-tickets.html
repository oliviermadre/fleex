Tickets en pixel

Chaque type de ticket tel que le skin pixel le dessine, par le vrai renderer : sur des convoyeurs, en haut tels quels, en bas écartés par un filtre (grisés). Un même petit plancher à chaque palier, aux pixels de la page. Compare avec le rendu d'aujourd'hui et avec le jeton de Fleex.

Les sept cas

  • build · un marteau
  • fix · un insecte
  • review · un œil
  • ops · un engrenage à huit dents
  • lead · une mallette
  • think · une ampoule
  • sans type · une caisse

Sur chaque convoyeur, dans l'ordre : build, fix, review, ops sur la première ligne ; lead, think, sans type sur la deuxième. Les deux lignes du bas sont les mêmes, écartées par un filtre.

Ce qu'il y a derrière

Comment ils sont faits

  • Onze pixels de côté, dessinés pixel par pixel d'après l'icône que Fleex donne à chaque type ailleurs dans l'app : le contour sombre, l'intérieur dans la couleur du type, un reflet plus clair.
  • Toujours sur des pixels entiers, centrés sur la position du ticket : aucun pixel à moitié allumé, à aucun palier.
  • Écarté par un filtre, le même dessin en gris, pâli : il reste là, on le reconnaît, il ne crie pas.
  • Pour retoucher un dessin, laisse un commentaire sur cette page (lequel, et ce qui ne va pas) : chaque icône est une grille de onze lignes dans skins/pixel.ts.
